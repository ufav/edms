# Форматы файлов для импорта

## 1. Импорт трансмитталов

### Общие требования
- **Формат файла:** Excel (.xlsx, .xls)
- Файл должен содержать **лист с указанным в настройках именем** (например: "Sheet1", "Transmittal")

### Метаданные (опционально)
В любом месте листа (обычно в шапке) может быть ячейка с лейблом номера трансмиттала:

| Ячейка A | Ячейка B |
|---|---|
| **Transmittal No:** | ABC-TRM-001 |

- Лейбл задается в настройках импорта (например: `Transmittal No:`)
- Значение ищется в соседней ячейке (справа, слева, снизу или сверху — настраивается)

### Таблица документов (обязательно)

Должна содержать **строку заголовков** с колонками:

| Обязательное поле | Описание | Пример заголовка |
|---|---|---|
| **Номер документа** | Номер документа в системе | `Document Number`, `Doc No`, `Номер документа` |
| **Статус** | Код/статус ревизии | `Status`, `Code`, `Review Status` |

**Пример структуры:**

| Document Number | Rev | Title | Status |
|---|---|---|---|
| 020-3300-PPP-DSW-001 | A01 | Drawing 1 | Code 1 |
| 020-3300-PPP-DSW-002 | A01 | Drawing 2 | Code 2 |

### Альтернатива: Номер трансмиттала в таблице

Если номер трансмиттала НЕ в метаданных, он может быть колонкой в таблице:

| Transmittal No | Document Number | Status |
|---|---|---|
| ABC-TRM-001 | 020-3300-PPP-DSW-001 | Code 1 |
| ABC-TRM-001 | 020-3300-PPP-DSW-002 | Code 2 |

### Маппинг статусов

В настройках импорта нужно указать соответствие входящих кодов системным статусам:

| Входящий статус | Системный статус |
|---|---|
| Code 1 | Approved |
| Code 2 | Approved with Comments |
| Code 3 | Rejected |
| Code 4 | Not Reviewed |

### Важные требования

1. **Названия колонок должны точно совпадать** с настройками импорта
2. **Номера документов должны существовать** в проекте (иначе импорт завершится с ошибкой)
3. У документов должны быть **ревизии** (последняя ревизия будет привязана к трансмитталу)

## 2. Массовая загрузка документов

### Общие требования
- **Формат файла:** Excel (.xlsx, .xls)
- Файл должен содержать **строку заголовков** с названиями колонок

### Обязательные колонки

| Колонка | Алиасы (варианты названия) | Описание |
|---|---|---|
| **number** | `Document Number`, `DocumentNumber`, `DocumentId`, `Document_Id`, `Document Number*` | Уникальный номер документа |
| **title** | `Title`, `Document Title`, `DocumentTitle`, `Title*` | Название документа |

### Опциональные колонки

| Колонка | Алиасы | Описание |
|---|---|---|
| **secondary_title** | `Secondary Title`, `SecondaryTitle`, `Secondary_Title` | Дополнительное название |
| **discipline** | `Discipline`, `Discipline*` | Код дисциплины (должен существовать в проекте) |
| **document_type** | `Document Type`, `DocumentType`, `Document_Type` | Код типа документа (должен существовать в проекте) |
| **content_language** | `Language`, `Content Language`, `ContentLanguage` | Код языка контента |

### Пример структуры Excel

| Document Number | Title | Secondary Title | Discipline | Document Type |
|---|---|---|---|---|
| 020-3300-PPP-DSW-001 | Drawing Plan A | План A | PPP | DSW |
| 020-3300-PPP-DSW-002 | Drawing Plan B | План B | PPP | DSW |
| 020-3300-ELE-SCH-001 | Electrical Scheme | Схема | ELE | SCH |

### Прикрепление файлов документов

- Файлы документов загружаются **отдельно** вместе с Excel-файлом метаданных
- **Имя файла должно совпадать с номером документа** (без расширения)
  - Например: документ `020-3300-PPP-DSW-001` → файл `020-3300-PPP-DSW-001.pdf`
- Система автоматически сопоставит файлы с документами по номеру

### Важные требования

1. **Заголовки могут содержать `*`** (звездочки игнорируются при парсинге)
2. **Регистр не важен** (`Document Number` = `document number` = `DOCUMENT NUMBER`)
3. **Пробелы и подчеркивания взаимозаменяемы** (`Document Number` = `Document_Number`)
4. **Дисциплины и типы документов должны быть привязаны к проекту** (иначе будут ошибки)
5. Для успешного распознавания заголовков требуется **минимум 3 совпадения** среди известных колонок, включая `number` и `title`
