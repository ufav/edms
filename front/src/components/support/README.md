# Support Components

Эта папка содержит компоненты для работы с системой поддержки (тикеты).

## Компоненты

### SupportChatDialog
Основной компонент для общения в тикете поддержки.
- Отображает сообщения в формате чата (WhatsApp-like)
- Поддерживает отправку текстовых сообщений и файлов
- Real-time обновления через WebSocket
- Просмотр изображений в full-screen режиме
- Кнопка "Вернуть в работу" для закрытых тикетов

### SupportTicketDialog
Диалог для создания нового тикета поддержки.
- Ввод темы и сообщения
- Загрузка файлов (изображения, документы)
- Валидация размера и типа файлов
- Локализация ошибок

### SupportTicketsListDialog
Диалог со списком тикетов пользователя.
- Отображение всех тикетов пользователя
- Фильтрация по статусу
- Открытие чата для конкретного тикета

### SupportFab
Плавающая кнопка для быстрого создания тикета.
- Всегда видима на страницах
- Открывает диалог создания тикета

## Хуки

### useSupportWebSocket
Кастомный хук для работы с WebSocket подключением.
- Автоматическое подключение/отключение
- Обработка сообщений в реальном времени
- Переподключение при обрыве связи
- Ping/pong для keep-alive

## Использование

```tsx
import { SupportFab, SupportChatDialog, SupportTicketDialog } from './support';

// В Layout.tsx
<SupportFab />
<SupportChatDialog
  open={chatOpen}
  ticketId={selectedTicketId}
  onClose={() => setChatOpen(false)}
/>
```

## API

Все API методы находятся в `src/api/client.ts`:
- `supportApi.createTicket()` - создание тикета
- `supportApi.getTickets()` - получение списка тикетов
- `supportApi.getTicket()` - получение тикета с сообщениями
- `supportApi.sendMessage()` - отправка сообщения
- `supportApi.reopenTicket()` - возврат тикета в работу
- `supportApi.downloadFile()` - скачивание файла

## Интеграция

### Telegram
- Тикеты автоматически отправляются в Telegram бот
- Администраторы могут отвечать через бот
- Уведомления приходят в веб-интерфейс

### WebSocket
- Real-time обновления сообщений
- Автоматическое переподключение
- Поддержка нескольких подключений к одному тикету

### Уведомления
- Уведомления при ответе поддержки
- Уведомления при закрытии тикета
- Открытие чата по клику на уведомление
