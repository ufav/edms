# Docste

## 2. Проблема

### Три критических риска, которые съедают бюджет проекта

**💰 Финансовые потери**

Строительство по старым ревизиям чертежей — до 10% бюджета на переделки

**⏱️ Операционный паралич**

Поиск документа в почте и мессенджерах занимает до 30% времени инженера

**⚖️ Юридические риски**

Отсутствие фиксации передачи документов контрагентам

---

## 3. Решение

### Docste — это экосистема, которая меняет работу проекта

**Центральный узел проекта**

Все участники (Заказчик, ГИП, Подрядчик) работают в одном актуальном поле

**Цифровой контроль**

Каждое действие залогировано, каждая ревизия под контролем

**Результат**

Вы точно знаете, кто, когда и какой документ утвердил

---

## 4. Основные возможности

### Три кита платформы

**Колонка 1: Smart-хранилище**

Просмотр DWG/PDF без спецсофта (Autodesk API), авто-нумерация, быстрый импорт

**Колонка 2: Умный Workflow**

Документ сам идет по маршруту (Draft → Review → Approved). Система пушит ответственных, если они затягивают сроки

**Колонка 3: Трансмитталы (Киллер-фича)**

Официальная передача пакетов документов контрагентам с подтверждением получения

## 5. Аналитика и Контроль
