## 🎯 ПРЕДЛОЖЕНИЯ ПО ГРАФИКАМ

### 1. 📈 Динамика создания документов (Линейный график)
**Описание:** График показывает количество созданных документов по дням/неделям/месяцам

**Данные:**
- `Document.created_at` - дата создания
- Группировка по дням/неделям/месяцам
- Фильтр по выбранному проекту

**Визуализация:**
- Линейный график (line chart)
- Ось X: даты
- Ось Y: количество документов
- Возможность выбора периода (7 дней, 30 дней, 90 дней, все время)

**Польза:**
- Видно активность проекта
- Можно отследить пики загрузки документов
- Планирование ресурсов

**Приоритет:** 🔴 Высокий

---

### 2. 🥧 Распределение документов по статусам workflow (Круговая диаграмма)
**Описание:** Показывает, сколько документов в каждом статусе workflow

**Данные:**
- `DocumentRevision.workflow_status_id`
- Статусы: Draft, In Review, Approved, Rejected, Approved with Comments, Not Reviewed

**Визуализация:**
- Pie chart или Donut chart
- Цвета для каждого статуса
- Процент и абсолютное значение

**Польза:**
- Быстрый обзор состояния документов
- Видно, сколько документов на согласовании
- Видно завершенные документы

**Приоритет:** 🔴 Высокий

---

### 3. 📊 Распределение документов по типам (Столбчатая диаграмма)
**Описание:** Показывает количество документов каждого типа

**Данные:**
- `Document.document_type_id`
- Названия типов документов

**Визуализация:**
- Bar chart (горизонтальный или вертикальный)
- Сортировка по количеству
- Ограничение топ-10 или все

**Польза:**
- Видно, какие типы документов наиболее популярны
- Планирование структуры проекта

**Приоритет:** 🟡 Средний

---

### 4. 📈 Динамика трансмитталов (Линейный график)
**Описание:** Показывает количество отправленных/полученных трансмитталов по времени

**Данные:**
- `Transmittal.created_at` - дата создания
- `Transmittal.direction` - 'out' (отправленные) или 'in' (полученные)
- `Transmittal.status` - статус

**Визуализация:**
- Line chart с двумя линиями
  - Отправленные трансмитталы
  - Полученные трансмитталы
- Ось X: даты
- Ось Y: количество

**Польза:**
- Видно активность обмена документами
- Отслеживание коммуникации с контрагентами

**Приоритет:** 🟡 Средний

---

### 5. ⏱️ Среднее время обработки ревью (Столбчатая диаграмма)
**Описание:** Показывает среднее время от создания ревью до одобрения/отклонения

**Данные:**
- `DocumentRevision.created_at` - когда ревью началось
- `DocumentWorkflowHistory.created_at` - когда статус изменился на Approved/Rejected
- Разница = время обработки

**Визуализация:**
- Bar chart
- Группировка по дисциплинам или типам документов
- Среднее время в днях

**Польза:**
- Видно, где задерживается согласование
- Оптимизация workflow
- Планирование сроков

**Приоритет:** 🟡 Средний

---

### 6. 📊 Топ дисциплин по количеству документов (Столбчатая диаграмма)
**Описание:** Показывает дисциплины с наибольшим количеством документов

**Данные:**
- `Document.discipline_id`
- Группировка и подсчет

**Визуализация:**
- Horizontal bar chart
- Топ-10 дисциплин
- Сортировка по убыванию

**Польза:**
- Видно наиболее активные дисциплины
- Распределение нагрузки

**Приоритет:** 🟢 Низкий (похоже на существующие прогресс-бары)

---

### 7. 📈 Распределение ревью по статусам (Круговая диаграмма)
**Описание:** Показывает статусы всех ревью

**Данные:**
- `DocumentRevision.workflow_status_id` для документов в статусе In Review
- Статусы ревью

**Визуализация:**
- Pie chart
- Цвета для каждого статуса

**Польза:**
- Обзор состояния согласований
- Видно, сколько ревью ожидает ответа

**Приоритет:** 🟢 Низкий (частично покрыто статистическими карточками)

---

### 8. 👥 Активность пользователей (Столбчатая диаграмма)
**Описание:** Показывает, кто больше всего создает документы/ревью

**Данные:**
- `Document.created_by`
- `DocumentRevision.uploaded_by`
- Группировка по пользователям

**Визуализация:**
- Horizontal bar chart
- Топ-10 пользователей
- Количество созданных документов/ревизий

**Польза:**
- Видно наиболее активных участников проекта
- Распределение нагрузки

**Приоритет:** 🟡 Средний

---

### 9. 📅 Календарь активности (Heatmap)
**Описание:** Календарная сетка, показывающая активность по дням

**Данные:**
- `Document.created_at`
- `Transmittal.created_at`
- Группировка по дням

**Визуализация:**
- Calendar heatmap (как в GitHub)
- Интенсивность цвета = количество действий
- Месяц/квартал/год

**Польза:**
- Видно паттерны активности
- Планирование работы

**Приоритет:** 🟢 Низкий

---

### 10. 📊 Распределение документов по областям (Area chart)
**Описание:** Показывает количество документов по областям (areas)

**Данные:**
- `Document.area_id`
- Названия областей

**Визуализация:**
- Stacked area chart или bar chart
- Группировка по областям

**Польза:**
- Видно распределение документов по областям проекта
- Планирование структуры

**Приоритет:** 🟢 Низкий

---

### 11. ⏰ Время до просрочки ревью (Гистограмма)
**Описание:** Показывает, сколько ревью просрочено и на сколько дней

**Данные:**
- `DocumentRevision.created_at`
- `WorkflowPresetSequence.due_days`
- Расчет: `due_date = created_at + due_days`
- Разница с текущей датой

**Визуализация:**
- Histogram или bar chart
- Группировка по диапазонам дней просрочки:
  - 0-3 дня
  - 4-7 дней
  - 8-14 дней
  - 15+ дней

**Польза:**
- Видно критичность просрочек
- Приоритизация работы

**Приоритет:** 🟡 Средний

---

### 12. 📈 Тренд закрытия документов (Линейный график)
**Описание:** Показывает, сколько документов было закрыто (Approved/Rejected) по времени

**Данные:**
- `DocumentWorkflowHistory.created_at` где статус = Approved/Rejected
- Группировка по дням/неделям

**Визуализация:**
- Line chart
- Ось X: даты
- Ось Y: количество закрытых документов

**Польза:**
- Видно скорость завершения документов
- Прогресс проекта

**Приоритет:** 🟡 Средний
